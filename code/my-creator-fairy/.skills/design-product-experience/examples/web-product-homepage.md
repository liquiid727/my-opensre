# Example: General Web Product Introduction

## Product Truth

A service lets users search real community workshops, inspect spaces and equipment, review access rules, reserve a time, and receive confirmation.

## Story Arc

1. Literal offer and real venue image
2. Current access problem
3. Search-to-reservation workflow
4. Workspace inspection
5. Rules and trust conditions
6. Reservation confirmation
7. Start-search CTA

## Surface Choice

Use a responsive scrolling introduction page rather than Slidev when public mobile search and booking entry matter. Preserve the same chapter logic and progressive workflow explanation.
