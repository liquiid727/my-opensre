# Example: Creator Tool Introduction Deck

## Product Truth

Creators import clips, use transcript-based rough cuts, compare versions, undo changes, and export an edit decision list.

## Story Arc

1. Cover with the artifact as the primary visual
2. Documentary editing friction
3. Full creation loop
4. Transcript-to-timeline mechanism
5. Version comparison
6. Undo and provenance
7. Export contract
8. Three editing scenarios
9. Open workspace CTA

## Visual Direction

Use real timeline, transcript, comparison, and export states. Keep the canvas inspectable and controls secondary. Avoid decorative AI imagery.
