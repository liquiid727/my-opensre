# Example: AI Gateway Introduction Deck

## Product Truth

A self-hosted gateway validates API keys, performs weighted provider routing, falls back on timeout, and records request traces.

## Story Arc

1. Cover: product name and self-hosted AI gateway category
2. Direct-provider operational problems
3. Landscape comparison
4. Gateway position in the request path
5. Progressive request reveal
6. Timeout and fallback trace walkthrough
7. Ownership and deployment boundaries
8. Quickstart prerequisites
9. Verified install command and expected trace
10. Documentation and source CTA

## Motion

Use `slide-left` through the request lifecycle and `fade-out` before quickstart. Reveal request stages with `v-click`. Do not simulate live traffic.
